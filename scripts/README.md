# scripts/

Developer / QA helpers (not shipped in the app).

| Script | What it does | How to run |
|--------|--------------|------------|
| `check.py` | The one gate: runs `format`, `lint`, `types`, `arch`, `qml` and `test`, or `all` of them in that order, stopping at the first red step. Tools come from the active environment (`uv sync --locked --extra dev --extra gui`); jscpd runs through `npx` at its pinned version, so Node is the one prerequisite outside the lock. | `python scripts/check.py [format\|lint\|types\|arch\|qml\|test\|all]` |
| `check_qml.py` | The `qml` and `format` steps' QML half: `pyside6-qmllint` over every app QML file and `_preview.qml` with every finding fatal (only the ahead-of-time `compiler` category stays off), or with `--format` a `pyside6-qmlformat` pass over copies that fails with the diff when any file would change. | `python scripts/check_qml.py [--format]` |
| `render_qml.py` | Renders a QML screen to a PNG **offscreen** (no display needed), seeded with sample state, so the Qt/QML UI can be reviewed against the design screenshots. | `python scripts/render_qml.py [summary\|extract\|batch\|config\|firstrun] [dark\|light] [out.png]` |
| `check_binary.py` | Checks a built binary: runs it offscreen with `--smoke-test --smoke-result <file>`, passes when it exits 0 and the file holds `DocSummarizer <version> smoke ok`, and holds its size between 150 MB (a build without Qt falls under it) and the size measured on that OS plus 15 %. | `python scripts/check_binary.py dist/DocSummarizer[.exe]` |
| `check_commits.py` | Checks commit messages: a Conventional Commits subject (`type(scope): description`, at most 72 characters, no `!` after the type, no trailing `.` or `!`) and no `BREAKING CHANGE:` footer. Subjects git writes itself (`Merge …`, `Revert "…"`, `fixup!`) pass. The `commit-msg` hook checks each new message; CI checks every commit a push or pull request adds. | `python scripts/check_commits.py <message-file>` or `--range <base> <head>` |
| `mutation.py` | Mutation testing with mutmut (`[tool.mutmut]` in `pyproject.toml`): `--changed <ref>` runs the mutants in the package modules changed since the merge base with `<ref>`, `--all` runs every mutant, each from a fresh `mutants/` copy on half the cores. Prints the score (killed or timed-out mutants over all run) and fails under `MUTATION_THRESHOLD`, listing the survivors. Linux or macOS. | `python scripts/mutation.py --changed origin/master` or `--all` |
| `_preview.qml` | Item-rooted mirror of `Main.qml`'s shell used by `render_qml.py` and `tests/test_qml_screens.py` (an `ApplicationWindow` can't be grabbed the same way). | — |
| `eval/run.py` | Runs the evaluation tiers, rescoring, comparisons and checks against a local corpus and model; see `--help`. | `python scripts/eval/run.py --eval-dir <eval-dir> --tier smoke --model <gguf>` |
